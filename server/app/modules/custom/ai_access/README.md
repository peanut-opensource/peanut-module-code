# AI 接入配置

`custom.ai-access` 面向当前租户提供服务商、令牌、模型的管理后台。现有制作助手及其历史配置、任务由原模块管理。

实例维护者在后端环境中设置 `AI_ACCESS_ALLOWED_ORIGINS`，以逗号分隔精确 HTTPS origin（包括非默认端口）。租户只能启用和调用实例已登记的地址。实例维护者应确认域名及其解析目标属于已批准的 AI 服务。

1. 登记服务商标识、名称、HTTPS 地址和 API 前缀。每个服务商的地址和前缀固定，改地址应创建新的服务商记录。
2. 登记其模型与稳定标识，填写远端实际模型名，按文本、生图能力分别选择协议。服务商与模型的优先级数值越高越优先。
3. 登记其调用令牌。选择具体可用模型或明确填写 `*` 允许此服务商内全部模型，启用后才可参与调用。令牌用系统密钥环加密，接口只返回配置状态。
4. 按原生租户模块权益和角色配置分别授予查看、维护或调用权限。

消费模块声明对 `custom.ai-access` 的依赖，通过容器注入公开的 `Custom\Modules\AiAccess\Contract\AiClient`，从已授权的租户后台业务入口调用：

```php
$reply = $ai->generateText($prompt, $requestKey, model: 'qwen-plus', provider: 'aliyun');
$image = $ai->generateImage($prompt, $requestKey);
```

显式选择只能命中对应配置。省略时，按能力和输入上限寻找配置，依次按服务商优先级、模型优先级选择，未指定令牌时在有权限的启用令牌间轮询。若多个服务商使用同一令牌标识，显式传该标识时也应指定服务商。调用结果含实际选中的标识与服务商回执。文本支持 OpenAI Chat Completions、Anthropic Messages，生图支持 OpenAI Images 的单张 PNG 响应。

调用者校验业务权限、输入来源和发送确认，在业务事务之外调用，提供同一次操作的稳定请求键，并保存需要进入业务流程的返回结果。相同成员的相同请求键只会发起一次供应商请求，重复提交可通过 `requestStatus` 查询现有回执。回执保存选择和可确认的原始用量，内容和图像仅通过调用返回。当前目标覆盖同步租户后台调用。

后续在本模块增加费用与明细。计费情形包括内部用户之间计费、免计费和直接使用远程算力，远程供应商成本另行统计。本版保存供应商返回的原始用量。
